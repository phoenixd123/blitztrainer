Grind the demon.Skip the spreadsheet.

Blitz Trainer runs the Blitzkrieg practice method inside Geometry Dash. It builds your stages, counts every pass and moves your spawn to the next section you haven't beaten.

Download .geode View source

Geometry Dash 2.2081 with Geode 5.10.1 or newer. Windows, macOS, Android and iOS.

Set up in a minute

You need a copy of the level with start positions in it. 12 to 18 start positions works best.

  1. Install Geode

    Get it from geode-sdk.org if you don't have it yet.

  2. Add the mod

    In game open Geode, then Mods, then Install from file, and pick phoenixd123.blitz-trainer.geode. Geode installs the Node IDs dependency for you. Restart the game.

  3. Start a profile

    Open your startpos copy, pause, press the pink Blitz Trainer button and choose Classic or Lite.

  4. Play

    The HUD shows your stage and target. When a range is beaten your next respawn moves on by itself.

What it does

Moves your spawn for you

Finish a range and the next respawn starts at the next unfinished one. No startpos switcher mod needed.

Knows which start position you used

It checks where you actually spawned, not just which start position the game says is selected, so runs land on the right range.

Shows the game's own percentages

It matches GD's 2.1 or 2.2 percentage display automatically, so 41% in the mod is 41% in the level.

Consistency mode

Require 1 to 10 passes per range, and optionally make them count only in a row.

Classic or Lite stages

Classic is Rudder's original method. Lite uses windows of 1, 2, 4, 8 sections for long levels, with far fewer ranges.

Death heatmap

See where you die most and which ranges have the lowest pass rate.

Keeps progress when the level changes

Added or moved a start position? Rebuild keeps the stats of every range whose ends didn't move.

Honest runs only

Noclip and speedhack attempts are ignored. Lag spikes and speed-change triggers aren't mistaken for cheats.

Change any of these in the mod's settings.

How runs count

Every attempt goes to one target range in your current stage. The mod picks it in this order:

  1. An unfinished range you fully beat, earliest first.
  2. The unfinished range that starts where you spawned.
  3. The unfinished range you got furthest through.
  4. The same rules for finished ranges, which then get extra passes.

The target gets the attempt, the time and your best progress. With "Long runs credit shorter ranges" on, a run that beats several unfinished ranges gives each of them a pass.

Attempts from practice-mode checkpoints don't count, because they don't start at a start position. Turn on "Track practice mode" to count practice attempts that do.

Questions

Does it work on GD 2.2091?

Not yet. Geode itself doesn't support 2.2091 yet. A new build will follow once it does.

Does it work in platformer levels?

No. The Blitzkrieg method is built around classic levels.

Where is my progress saved?

In your GD save folder under geode/mods/phoenixd123.blitz-trainer/profiles, one file per level. You can also export a profile to your clipboard and import it on another device.

My level has start positions with an order or reverse gameplay.

Sections always follow left-to-right position, so play order can differ in those levels. The mod warns you when it finds them.

I found a bug.

Open an issue on GitHub and attach the newest file from your geode/logs folder.
